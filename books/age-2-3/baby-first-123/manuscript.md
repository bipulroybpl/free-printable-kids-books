# Manuscript: Baby's First Learning 123 (Ages 2-3)

Total pages: 12 (cover + 10 number pages + back cover). Every number page uses
the same split-panel layout as `baby-first-abc` for series consistency: a
glossy 3D numeral with a cute face on the left (light neutral background),
and the matching count of one friendly object on the right (bright
single-color background), clearly spaced apart so a caregiver can point to
each one while counting aloud with the child.

Object choices favor clear, distinct, easily countable shapes at every
quantity from 1 to 10 — nothing that reads as a small loose/graspable item.

## Production notes

- Every object set must be arranged with visible gaps between each item —
  never overlapping or clustered — so the layout itself supports counting
  practice, not just recognition.
- The left-panel numeral treatment (glossy 3D, googly cartoon eyes, same
  smile style, same light neutral background) stays pixel-consistent across
  all 10 pages, matching the visual system established in `baby-first-abc`.
- Object counts must be exact and unambiguous at a glance — no partially
  obscured or cut-off items at the edge of the frame.
